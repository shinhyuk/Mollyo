# 몰려 Mollyo

우리 반, 지금 어디 몰렸어?

고등학생이 반 친구들과 쓰는 웹앱(PWA)입니다. 어제 동선 공유, 익명 인원 지도, 반 칭찬 투표 세 가지로 시작합니다.

## 지금 되는 것 (v0.1, 서버 없음)

| 화면 | 내용 | 데이터 |
|---|---|---|
| 가입 | 만 14세 확인, 학교·학년·반·별명 | 기기 저장 |
| 동선 | 오늘 동선 기록, 어제 동선 보기, "친구에게 보이는 모습" 미리보기 | 내 동선은 실제, 친구는 데모 |
| 몰려 | 사람이 몰린 곳을 인원수로만 표시 | 데모 |
| 투표 | 반 친구 칭찬 투표 | 데모 |
| 설정 | 공유 켜기/끄기, 숨김 구역, 데이터 삭제 | 기기 저장 |

모든 데이터는 기기의 localStorage에만 있습니다. 서버로 나가는 것은 지도 타일 요청뿐입니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 위치 처리 규칙 테스트
npm run build    # dist/ 생성
```

위치 기록은 HTTPS 또는 localhost에서만 동작합니다.

## 위치 정보 규칙

이 앱의 사용자는 미성년자입니다. 아래 규칙은 기능보다 우선합니다. 구현은 `src/lib/geo.ts`, 값은 `src/lib/store.ts`에 있습니다.

1. **기본값은 전부 꺼짐.** 동선 공유와 인원 지도 참여는 본인이 켜야 합니다.
2. **지금 위치는 누구에게도 보여주지 않는다.** 친구에게 보이는 것은 하루 지난 동선뿐입니다.
3. **원본 좌표는 기기 밖으로 나가지 않는다.** 공유되는 동선은 250m 격자로 뭉갠 것입니다.
4. **숨김 구역(집 등) 반경 300m는 공유에서 빠진다.**
5. **서로 공유.** 내 동선을 공유해야 친구 동선이 보입니다. 서로 친구인 경우만 해당합니다.
6. **인원 지도는 3명 미만인 칸을 표시하지 않는다.** 이름·프로필은 붙지 않습니다.
7. **동선은 7일 뒤 삭제한다.**
8. **만 14세 미만은 가입할 수 없다.** 생년월일은 확인만 하고 저장하지 않습니다.

## 알려진 한계

- **웹앱은 화면이 꺼지면 위치를 기록하지 못합니다.** 하루 동선을 자동으로 남기려면 네이티브 래핑(Capacitor 등)과 백그라운드 위치 권한이 필요합니다. 지금은 화면을 켜 둔 동안만 기록됩니다.
- 학교 목록, 친구, 인원수, 투표 상대는 전부 가짜 데이터입니다(`src/lib/mock.ts`).
- 반 인증(초대 링크, 친구 3명 승인)은 아직 없습니다.

## 다음 단계

1. 서버 붙이기: 계정, 반, 친구 관계, 투표 저장 (`src/lib/store.ts`의 함수만 교체)
2. 반 인증: 초대 링크 + 같은 반 3명 승인 + 정원 35명 + 신고 3건 퇴출
3. 학교 목록: 나이스 교육정보 개방 포털 API 연동
4. 신고·차단 기능 (스토어 심사 필수 항목)
5. 스토어 배포: Play(TWA) → App Store(Capacitor)

## 출시 전에 반드시 확인할 것

법률 자문이 아니며, 출시 전에 전문가 확인이 필요합니다.

- 위치기반서비스사업 신고 (서버가 다른 사람의 위치를 처리하기 시작하는 시점 이전)
- 위치정보 이용약관, 개인정보 처리방침
- 미성년자 대상 서비스의 보호자 고지·동의 범위
- 재직 중이라면 회사 겸업 규정

## 구조

```

  lib/store.ts      데이터 계층 (지금은 localStorage)
  lib/mock.ts       데모 데이터
  components/       지도
  screens/          가입, 동선, 몰려, 투표, 설정
  styles.css        네오 브루탈리즘 스타일
public/             PWA manifest, service worker, 아이콘
```
